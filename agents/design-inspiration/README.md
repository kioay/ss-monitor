# 竞品素材侦查

竞品素材侦查用于收集和整理 FPS/TPS 竞品中的武器皮肤、角色皮肤及相关视觉设计素材，帮助美术与策划快速查看可参考的视频和图片来源。

## 使用方式

1. 打开 Agent 后选择需要关注的竞品包、素材分类、时间范围和排序方式。
2. 可按关键词聚焦题材或表现形式，例如科幻、近战、检视或通行证。
3. 点击采集后查看素材报告；报告按武器皮肤、角色皮肤和综合参考归类，并标注竞品、来源和热度信息。
4. 需要打开原始内容时，使用报告中的来源链接或进入素材库查看完整条目。

## 输入

- 竞品包：留空时检索全部已配置竞品。
- 素材分类：武器皮肤、角色皮肤或综合参考。
- 排序方式：按相关性、热度或最新发布时间排列。
- 时间范围：最近 1 至 720 小时。
- 关键词：可选，用于聚焦特定设计题材。

## 输出

- 中文素材侦查报告，列出值得参考的热门设计方向。
- 按品类整理的竞品素材索引，包含竞品游戏、来源标题和可打开的来源链接。
- 对钉钉等外部会话，保留素材来源和详情入口，并将可用的真实封面作为任务图片产物推送；详情页素材卡仍可查看完整封面。

## 注意事项

- 仅将有视频或图片的条目作为设计参考候选。
- 键盘、鼠标、鼠标垫、耳机等外设联名不属于武器或角色设计素材，不会进入报告和图片推送。
- 素材来源和封面受上游平台可访问性影响；报告不会虚构缺失的图片、热度或链接。
- 该 Agent 读取现有素材库索引，不会改变原舆情监测网页或其采集任务。
