# SS Monitor

SS Monitor 汇总 SS1、SS2 监控窗口内的舆情数据，帮助运营快速判断风险和数据源健康状态。

## 它能做什么

- 生成当前监控窗口的中文舆情摘要，列出风险、重点条目和处置建议。
- 检查监控服务、配置接口和数据源是否可用。
- 不会主动发送钉钉测试消息，也不会修改生产监控配置。

## 使用方法

1. 打开 Agent 后选择 SS1、SS2 或两者。
2. 设置监控窗口、条目上限和可选补充关键词。
3. 点击“生成摘要”查看舆情判断，或点击“检查健康”确认服务状态。
4. 在结果页查看结论、重点条目、建议和本次任务产物。

## 输入

- 监控地址：SS Monitor 服务地址，默认使用内网生产服务。
- 项目：`SS1`、`SS2`，至少选择一个。
- 窗口：1 至 720 小时。
- 条目上限：1 至 1000 条。
- 补充关键词、问题：可选，用于限定本次关注重点。

## 输出

- 舆情摘要：包含结论、风险、来源健康、重点条目和建议。
- 健康检查：包含监控服务、健康接口和配置接口状态。
- 任务产物：摘要、监控快照、运行清单和执行日志。

## 注意事项

- 摘要依据当前监控数据生成；数据源不可用或数据过期时，结果会明确标注限制。
- BettaFish 语义分析仅作为辅助信号，不会单独把舆情判定为高风险。
- 任务失败时可先运行“检查健康”；若健康正常仍失败，请在 Agent 详情页提交问题并附任务编号。
